# `.working/` — không dựng theo thư mục này

Không file nào ở đây là tham chiếu để dựng. Nguồn sự thật là `DESIGN.md`, `EXPERIENCE.md`,
và các file trong `mockups/`.

## Dấu vết quyết định — giữ nguyên hiện trạng lúc quyết

Ba file dưới đây cố tình **không** được cập nhật theo token mới. Chúng ghi lại **cái gì đã
được chọn và chọn giữa những gì**, nên sửa chúng là xoá mất bằng chứng.

| File | Ghi lại |
|---|---|
| `direction-ban-tho.html` | Hướng thị giác bị loại — bản thô |
| `direction-ke-thua.html` | Hướng thị giác bị loại — kế thừa QuickTranslator |
| `direction-ban-viet-DA-CHON.html` | **Hướng đã thắng.** Còn mang `#7d766c` vì đó là màu lúc quyết định |
| `layout-2x2-variants.html` | Các cách ghép lưới 2×2, và cách nào thắng |

## Bản cũ đã bị thay — tiền tố `superseded-`

Sáu file dưới đây từng trùng tên với mockup hiện hành. Ai mở nhầm sẽ dựng theo bản sai —
hai trong số đó còn mang `#7d766c`, màu **đã bị loại vì trượt WCAG AA**. Đổi tên ngày
2026-08-03 để không còn bẫy đó. Bản hiện hành nằm ở `../mockups/` cùng tên.

- `superseded-reading-mode-typography.html`
