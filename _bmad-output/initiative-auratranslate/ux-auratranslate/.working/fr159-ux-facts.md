## 8. Accessibility floor (EXP §Accessibility Floor, EXP:234-245; DESIGN §Điều khiển, §Motion)
- AD-34: every action is a registered command in `CommandRegistry` with domain-prefixed dotted id; mouse handlers only `dispatch` a registered command; "thao tác nào chưa gán được phím" must be enumerable. A new action without a default key is allowed (`keys: undefined`, as for proofread accept/dismiss/ignore/revert).
- NFR17: translate a full Chapter without touching the mouse (open from Library, lookup, AI, promote, edit, merge, confirm, next chapter). `Enter` is newline, never confirm (IME conflict, EXP:309); confirm is `⌘Enter`; Alt-only chords are swallowed inside a translation cell by `commands/keys.ts` (EXP:312, use Mod+Alt).
- NFR20 (PRD:1071): every independent function reachable by mouse; 0 registered commands without a mouse route (except five AD-62 classes); a new command without a mouse route cannot enter the repo. Mouse placement doc: `tickets/epic-san-chuot/ux-san-chuot/`.
- Each mode/panel declares a focus entry point; never let focus fall to `body`; overlays return focus on close (UX-DR17); strip buttons that must not steal focus use `@mousedown.prevent` (Ẩn) or keep the cell focus; Dịch nhanh buttons do not keep focus on click.
- Focus visible: keyboard focus ring = border `primary` for inputs/buttons (no outer ring), Primary button keeps 2px `primary` ring offset 1px, menu items 2px inset ring; `forced-colors` fallback `outline: 2px solid Highlight`. Translation cell is the only exemption (`outline:none`, named `aura-allow-outline-none`; caret + margin bar + `surface-accent` bg carry focus).
- Colour not the sole carrier (WCAG 1.4.1): margin bars differ by luminance step (min 1,5:1 pairwise); icon toggles use shape (outline vs fill); disabled uses dashed border + colour; Glossary pending vs confirmed = underline vs colour only; proofreader kind = label text + underline colour (two kinds same shape, differ by colour only -> label in strip carries kind). DESIGN §Opacity: "Báo trạng thái đã xử lý: vạch lề đổi màu + dấu ✓ / ✕".
- Text contrast: all text >= 4,5:1 (`on-surface-variant` floor); stroke >= 3:1 for control borders (`control-rule`); text size floor `ui-md` 13px; line-height 1.66 floor for content text (DESIGN §Giãn dòng; grid body exempt) and multiples of 7px elsewhere (7px grid, `--space-unit: 7px`; control heights 28/35).
- Hit area: checkbox/radio 14px box in 28x28px hit area (WCAG 2.5.8); icon button square equal to height 28px.
- Reduced motion: `prefers-reduced-motion` removes all effects, mandatory (DESIGN §Motion); motion limits: new content 90ms opacity 0.4->1, no translate/scale, no effect > 150ms on hot path, no queued effects, no spinner (thin progress bar after 250ms).
- Screen reader support (VoiceOver/NVDA full ARIA) is out of v1 scope (EXP:245; PRD §3.2) but strips use `role=status`/`role=alert`, dialogs use `role=dialog aria-modal`.
- No `opacity` for text; no raw colours; no `z-index` without named exemption `aura-allow-z-index`; no `v-html` (AD-16); user/model text rendered as text only.
