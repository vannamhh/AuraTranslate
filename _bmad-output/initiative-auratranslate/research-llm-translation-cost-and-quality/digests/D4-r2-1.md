# D4 round 2 digest: Vietnamese-target MT quality (accessed 2026-10-27 for all)

Reading note: arXiv PDFs came back as raw streams through WebFetch; I saved the PDFs and converted them with pdftotext, so WMT25 and Hunyuan were read as full text. The WMT24++ HTML was read through WebFetch (summarised, so figure values were not visible).

## Findings
- **[LB]** WMT25 General MT included English-Vietnamese. The preliminary-ranking paper's appendix has a full en-vi table. AutoRank (1 = best): Shy-hunyuan-MT 1.0 (7B, GEMBA-ESA-CMDA 83.1 / GPT4.1 87.3 / MetricX-24 -4.5 / XCOMET-XL 0.623); Gemini-2.5-Pro 2.7 (82.3 / 88.6 / -5.6 / 0.539); CommandA-WMT 2.7; GPT-4.1 2.8 (82.9 / 88.1 / -5.7 / 0.533); DeepSeek-V3 3.2; Qwen3-235B 3.3 (79.9 / 84.1); Mistral-Medium 3.7; Claude-4 5.0 (78.2 / 81.5 / -6.7 / 0.494); Llama-4-Maverick 6.6; Gemma-3-12B 8.1; Gemma-3-27B 9.9; NLLB 15.5; ONLINE-G (Google Translate) 17.4. Source: https://arxiv.org/pdf/2508.14909 (appendix, "English-Vietnamese" table). Publisher: WMT organisers (Kocmi et al.). Pub 2025-08 (v2 2025-08-24). Confidence: medium-high for the ranking, low for human-level quality. Class: quality number. Read: full text.
  - Caveat from the same paper: these are automatic metrics only. The paper says human results will supersede them. Humans scored about 18 systems per pair, but the paper does not say whether en-vi was one of the human pairs (half the pairs were a multilingual automatic-only subtrack). The paper also names a limitation: some models are tuned to these metrics. The GPT-4.1 and Command A judges also take part in the ranking (GPT-4.1 is a competitor), and the paper notes GPT-4.1's language coverage is undocumented.
  - Gap between the top frontier models is small (AutoRank 2.7 to 2.8; GEMBA-CMDA 82.3 to 82.9). Claude-4 sits behind them on all four metrics. The test is English source only, in news, social, speech and literary domains.
- **[LB]** WMT25 pairs are English-to-X, plus cs-uk, cs-de and ja-zh. There is no zh-vi pair in the General task. Chinese-to-Vietnamese quality therefore has no WMT25 evidence. Source: same paper, intro. Confidence: high. Read: full text.
- **[LB]** Hunyuan-MT (arXiv 2509.05209) lists Vietnamese (vi) among its 33 supported languages. The main text reports only aggregates: FLORES-200 ZH-to-XX, XX-to-ZH, EN-to-XX, XX-to-EN, XX-to-XX, and WMT24pp. The aggregates cover many languages, so they say nothing about Vietnamese specifically. XCOMET-XXL on WMT24pp: Hunyuan-MT-7B 0.8585, Gemini-2.5-Pro 0.8250, Claude-Sonnet-4 0.8120, GPT-4.1 0.8032, DeepSeek-V3 0.8109. XCOMET-XXL on FLORES-200 ZH-to-XX: Gemini-2.5-Pro 0.9146, Claude-Sonnet-4 0.9013, GPT-4.1 0.8843, DeepSeek-V3 0.8848. These are aggregates and the authors' own report. Weights are on Hugging Face (tencent/Hunyuan-MT-7B, Chimera-7B) and GitHub. I found no hosted OpenAI-compatible endpoint in the paper. Source: https://arxiv.org/pdf/2509.05209. Publisher: Tencent. Pub 2025-09. Confidence: medium (vendor report). Class: quality number. Read: full text.
- WMT24++ (arXiv 2502.12404) includes vi_VN (Table 1, en-to-xx with new references and post-edits). The text gives only averages over 55 languages (frontier LLM ranks 1.5, 1.9, 2.1). Per-language scores are in Figures 10 to 18 as plots that I could not read. Source: https://arxiv.org/html/2502.12404. Publisher: Google. Pub 2025-02. Confidence: high that vi_VN is included, no numbers. Read: full text of the HTML (as summarised by WebFetch; figures unreadable).
- Qwen-MT (Alibaba Cloud Model Studio docs, page dated 2026-10-11) supports Vietnamese (code `vi`) in qwen-mt-plus, qwen-mt-flash and qwen-mt-turbo (92 languages) and in qwen-mt-lite (31 languages). The API is OpenAI-compatible, with DashScope SDK and REST also documented. Source: https://www.alibabacloud.com/help/en/model-studio/machine-translation. Publisher: Alibaba Cloud. Confidence: medium-high. Read: page via WebFetch summary.
- Qwen-MT prices (USD per 1M tokens, input / output), from the pricing page dated 2026-10-27: Singapore plus $2.46 / $7.37, flash $0.16 / $0.49, lite $0.12 / $0.36. China (Beijing) plus $0.259 / $0.775, flash $0.101 / $0.280, lite $0.086 / $0.229. The Singapore plus figure looks high next to the China price, so re-check it on the page. Source: https://www.alibabacloud.com/help/en/model-studio/model-pricing. Publisher: Alibaba Cloud. Confidence: medium (WebFetch summary, only the first 100k of 143k characters read). Read: snippet-level.
- No quality score for Qwen-MT on Vietnamese was found. Qwen3-235B (general LLM) ranks 3.3 on WMT25 en-vi, level with GPT-4.1 and Gemini-2.5-Pro on the reference-free GEMBA metrics (see the WMT25 finding).
- User voice (voz.vn thread "Tool dịch truyện bằng gemini", https://voz.vn/t/tool-dich-truyen-bang-gemini.1076131/ , via a search-engine summary, thread itself not opened): the tool splits files by chapter and spreads them over several API keys. Reported complaints: character names drift, so users build manual name tables and bulk-replace; stock Gemini reads smoother than a self-trained model but still mistranslates proper names; sensitive content is sometimes blocked. One user suggests Flash Lite for raw Chinese and Flash for names converted to English. Confidence: low (anecdotal, second-hand). Class: user-voice. Read: snippet.

## Per-question answers
1. WMT25: yes for English-Vietnamese, automatic scores only (above). Human ESA for en-vi unconfirmed: the findings paper (aclanthology 2025.wmt-1.22) was not read. Not found: any zh-vi pair.
2. WMT24++: vi_VN is present. No per-language numbers readable here. Next step: Figures 10 to 18, or the released data at github.com/google-research/mt-metrics-eval or the WMT24++ HF dataset.
3. Hunyuan-MT: open weights, a 7B model that ranks first on WMT25 en-vi by automatic metrics. No hosted API found (not searched on OpenRouter or SiliconFlow). Qwen-MT: Vietnamese supported, OpenAI-compatible, prices above. TranslateGemma and Gemma 3: Gemma-3-27B ranks 9.9 on en-vi, well below frontier models. TranslateGemma was not searched.
4. Vietnamese user voice: one source only, thin. Recurring problem is proper-name consistency; remedies are a glossary or convert-first step. No model-preference evidence worth using.
