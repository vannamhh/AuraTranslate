- `core/scope/store.rs`: `GlobalConfig::quick_translate_auto()` reads `app_config` / `quick_translate_auto`, true only for `on`; absent defaults off.

- `commands/aiconfig.rs`: `quick_ai_config_get` additionally returns `auto_enabled: boolean` (saved on AND dedicated complete) and `auto_eligible: boolean` (dedicated endpoint and model complete). Existing main fallback/readiness untouched. New setter `quick_ai_config_set_auto({ tier: 'global', enabled: boolean }) -> void`; Work rejected, invalid enable rejected, disable accepted without dedicated fields.
- `commands/aitranslate.rs`: `QuickTranslateTrigger` is required on both quick IPCs, `trigger: 'auto' | 'manual'`. Queue Rust argument order: app, context_example, trigger, run_id, retranslate, channel. Preview: app, texts, trigger, retranslate, run_id, channel. Both quick outcome unions gain `{ state: 'auto_off' }` and `{ state: 'paused' }`. Queue auto gate runs before quick ticket acquisition, preparation/keychain or network; preview reuses it but must remain manual from the Webview in this story. Gate returns auto_off before activity pause if config is off/incomplete. `auto` requires managed real generation state (missing state is an IPC error, never assumed idle). Manual bypasses auto gate.
- `AiTranslateGeneration` retains its exact next/is_current generation semantics and additionally owns activity count/revision behind a shared mutex. All four real send wires take an RAII activity guard before preparation; early exits drop it, otherwise it moves into the blocking closure and stays until actual execution ends. Cancel only changes generation; stale blocking executions keep activity nonzero until they finish. Quick calls never touch real generation/activity.
- Registered `ai_translate_activity({}) -> { revision: number, active_count: number }` snapshot. Versioned app event `ai-translate-activity-v1` carries the same payload on each start/end, including transitions 1→2 and 2→1. Subscribe before snapshot and reject older revisions in the Webview. No additional app state registration needed: activity belongs to existing `AiTranslateGeneration` state.
- Existing Rust manual IPC callers now provide the typed trigger. Webview callers and e2e direct IPC scripts still need explicit `trigger: 'manual'` unless exercising auto.
