### Commands (wire args are camelCase on the JS side; all four are `#[tauri::command(async)]`)
| command | args | returns |
|---|---|---|
| `tm_export_tier` | `tier: "work"\|"global"` | `string \| null` (path written; `null` = dialog cancelled) |
| `tm_open_import_preview` | `tier` | `TmxImportPreview \| null` (`null` = dialog cancelled, no plan left) |
| `tm_confirm_import` | none | `TmxImportSummary` |
| `tm_cancel_import` | none | `null` (harmless with no plan) |

Wire shapes (snake_case):
- `TmxImportPreview { file_name, tier: "work"|"global", unit_count, new_count, already_count, skipped_count }`. `already_count` = pairs already in the tier + repeats inside the file. `new_count == 0` is a valid preview (re-import), confirm then writes 0.
- `TmxImportSummary { inserted, already_count }` (`already_count` = pairs found in the tier when the transaction ran).

### Error codes (all `message_key` Unknown, webview maps by `code`)
`tm.tmx_malformed` (param `line`), `tm.tmx_no_body`, `tm.tmx_not_utf8`, `tm.tmx_too_large`, `tm.tmx_no_usable_pair`, `tm.tmx_read_failed` (retryable), `tm.tmx_write_failed` (retryable), `tm.no_pending_import`, `tm.dialog_path_invalid`, `tm.invalid_filter` (unknown tier, param `filter`,`value`), `work.none_open` (Work tier, no Work), store errors as elsewhere. A failed preview keeps the earlier plan; a failed confirm keeps the plan; success clears it.

- Export default names `tm_work.tmx` / `tm_global.tmx`; import filter tmx/xml.

### Risks
- Export drops XML-1.0-illegal control chars (U+0000-U+001F except tab/LF/CR, U+FFFE/FFFF) from text; round trip of such text is lossy. `\r` is written as `&#13;`.
- Import reads only `<seg>` text inside `<tuv>` inside `<tu>`; `<sub>` text counts as inline (dropped) per spec; DTD entities are unsupported (unknown entity is `tm.tmx_malformed`).
- Date validation is a range check on shape (no leap-day check); invalid `x-aura-created-at` falls back to `creationdate` then now.
